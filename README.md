# Сервис учёта доходов и расходов

## Описание приложения

Web-приложение для учёта личных финансов. Пользователь сможет записывать доходы и расходы, распределять операции по категориям, устанавливать бюджет на месяц и просматривать статистику.

## Основная функциональность

- Регистрация и авторизация пользователей.
- Добавление, редактирование и удаление доходов и расходов с указанием суммы, даты, категории и комментария.
- Создание собственных категорий доходов и расходов.
- Просмотр истории операций с фильтрацией по датам, категориям и типу операции.
- Расчёт баланса: разницы между внесёнными доходами и расходами.
- Просмотр статистики за выбранный период: общие доходы, расходы и распределение расходов по категориям.
- Установка общего месячного бюджета и отображение оставшейся суммы.

Каждый пользователь имеет доступ только к своим операциям, категориям и бюджету. Суммы учитываются в рублях, интеграция с банками не предусмотрена.

## Архитектура проекта

Приложение состоит из web-интерфейса и трёх backend-сервисов:

1. Сервис пользователей — хранит учётные записи, выполняет регистрацию и вход, выдаёт JWT для доступа к API.
2. Сервис операций — хранит доходы, расходы и категории, предоставляет API для управления ими.
3. Сервис аналитики — хранит настройки бюджета, получает операции по REST из сервиса операций и рассчитывает статистику за выбранный период.

Сервисы проверяют JWT и ограничивают доступ к данным текущего пользователя.

Пользователь работает с приложением через web-интерфейс. За регистрацию и вход отвечает сервис пользователей, за доходы, расходы и категории — сервис операций. Сервис аналитики запрашивает операции по REST и на их основе рассчитывает статистику. Настройки бюджета он хранит у себя. У каждого сервиса своя база данных.

Для хранения используется MySQL с отдельной базой данных для каждого сервиса.

## Используемые технологии

- Backend: Java 21, Spring Boot.
- Работа с базой данных: Spring Data JPA.
- База данных: MySQL.
- Авторизация: Spring Security, вход по логину и паролю.
- Frontend: HTML, CSS, JavaScript без дополнительных фреймворков.
- Взаимодействие сервисов: REST API.
- Сборка: Maven.
- Контроль версий: Git, GitHub.
